# 📅 Welche Kalenderwoche ist heute?

> A minimal, fast web app that answers one question: **What calendar week is it today?**

## ✨ Features

- 🕐 Instantly shows the current **ISO calendar week**
- 📱 Responsive design — works on mobile and desktop
- ⚡ Lightning fast, no unnecessary bloat
- 🇩🇪 Designed for the German-speaking market (KW = Kalenderwoche)

## 🛠 Tech Stack

Built with modern web technologies. [Try it on StackBlitz →](https://stackblitz.com/~/github.com/bernhardbrugger/welche-kalenderwoche-ist-heute)

## 🚀 Getting Started

```bash
npm install
npm run dev
```

## 💡 Why?

Because sometimes you just need to know what week it is — without ads, cookie banners, or slow page loads.
